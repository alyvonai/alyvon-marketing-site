# Alyvon marketing site — imagery to create

Only the images still to be produced. Send finished WebPs and they drop into the
`MediaFrame` wrappers already built on the pages — no layout changes needed.

## Art direction (every shot)
- **Palette:** cool white / `#F6F7F9` surface · brand orange `#DE4B12` · ink `#0B0D11` · secondary `#585F6A`. Warm, subtle backgrounds; no heavy gradients on the site chrome (individual creative pieces can be any brand color).
- **Type in art:** Archivo; JetBrains Mono for small labels/numbers.
- **No fabricated legible product data.** Use placeholder bars / clearly illustrative content. Any product‑UI shot is captioned "Product UI. Illustrative data."
- **Export:** WebP, ≤2880px wide. Hero ≤200 KB, section ≤120 KB.
- **Formats used on the site:** `4:3` (desktop/section), `4:5` (phone), `16:9` (wide), `1:1` (square).
